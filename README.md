# MA4N1: UATheorem
Repository to contain all relevant files and folders for the group project portion of the MA4N1: Theorem Proving With Lean Warwick Maths module.
We are seeking to prove the Universal Approximation Theorem for shallow neural networks, via the Stone-Weierstrass Approximation theorem, which involves considering algebras of continuous functions.

There is a PDF in the root folder which contains the proof structure; this may help to follow the proofs in the LEAN code.
